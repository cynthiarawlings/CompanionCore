# CompanionCore

CompanionCore is a modular AI companion platform designed to create persistent, character-driven AI agents with long-term memory, evolving relationships, and autonomous behavior.

Unlike traditional chatbots that rely on a single conversation history, CompanionCore separates personality, memory, emotions, goals, and tool usage into independent systems, allowing companions to maintain continuity across conversations.

## Vision

The goal of CompanionCore is to create AI companions that feel less like chatbots and more like persistent individuals.

Key design principles include:

- Persistent long-term memory
- Character-driven personalities
- Relationship progression
- Emotional state management
- Autonomous goals and behaviors
- Tool integration (web search, files, APIs)
- Local LLM support via Ollama

## Planned Technology

- ASP.NET Core Web API
- Blazor
- PostgreSQL
- Entity Framework Core
- Ollama
- Docker (planned)
- Azure (planned deployment)

Early development
